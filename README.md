# TempEase — Temperature Converter

TempEase is a responsive temperature conversion website built as part of my Oasis Infobyte Web Development and Designing Internship.

## Features
- Convert between Celsius, Fahrenheit, and Kelvin.
- Display all three temperature units at once.
- Validate invalid input and temperatures below absolute zero.
- Reset the converter with one click.
- Responsive design for mobile and desktop.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
